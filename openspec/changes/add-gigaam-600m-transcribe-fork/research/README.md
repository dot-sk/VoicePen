# Основа реализации GigaAM Multilingual 600M

Здесь сохранены наработки исследовательского сабагента для продолжения при apply. Исходники скопированы без изменений; `manifest.json` содержит исходные расположения, размеры и SHA-256. Подробные результаты измерений, аудио, расшифровки, веса, библиотеки и дампы остаются в игнорируемом `.local/asr-quality/`. Краткие выводы приведены в `implementation-evidence.md`.

## Что уже есть

| Материал | Как использовать |
|---|---|
| `scripts/convert_mlx.py` | Основа конвертера F16 MLX → GGUF: учёт 824 тензоров, обратное преобразование 75 Conv1d, CTC-словарь и frontend |
| `source.patch` | Патч пяти файлов против upstream `1dc22facfc931e2f8adb43924b0e38b9c46f83c7`: lifetime исправления диагностических дампов, экспериментальный whole-input режим, GPU CTC и измерения стадий |
| `scripts/build_runtime.py`, `benchmark.py`, `quantize.py` | Рабочие команды сборки, ограниченные по времени процессы, F16/Q8 и whole/stock25 прогоны |
| `scripts/reference.py`, `reference_f32.py`, `parity.py` | Экспорт MLX, сравнение промежуточных результатов и полного текста при одинаковой точности вычислений |
| `scripts/ab_head.py`, `compare_heads.py` | Чередующийся CPU/GPU A/B на одной библиотеке, проверка logits и текста |
| `scripts/score.py`, `finalize.py`, `record_verification.py` | WER/CER, четыре политики нормализации, происхождение артефактов и отчёты |
| `dependencies/` | Исходная ctypes-обвязка и замороженные scoring-политики, от которых зависят исследовательские скрипты |
| `python-environment.json` | Зафиксированные версии исследовательского окружения |

## Выбранный кандидат

Основной режим change: F16-хранение, F32-активации, энкодер Metal, CTC-проекция/поиск CPU, штатный planner окон до 25 секунд с контекстом до 2 секунд по сторонам. Он дал base WER/CER 8,0842% / 4,2985%, а с прежними допусками написания терминов 5,5140% / 1,9056%; медиана 253,62 мс. Это результаты 27 записей с тремя повторами, без времени загрузки и прогрева.

Whole-input C++ и matched-F32 MLX дали одинаковые тексты на 27/27 записях. Это доказательство для whole-input; matched-window oracle для выбранного режима ещё предстоит добавить. Измеренный CPU/GPU head A/B не показал убедительного общего ускорения. Q8 здесь медленнее F16.

## Как продолжать

1. Проверить `manifest.json` и брать исходники из этого каталога, если локальная исследовательская директория недоступна. Патч применим к указанному upstream через `patch -p1`; сначала выполнять `--dry-run` на чистом исходнике.
2. Начать production-конвертер с `convert_mlx.py`, параметризовать пути и валидировать конфигурацию. Сейчас в нём зафиксирован конкретный профиль; языковая metadata перечисляет только ru/en/kk и требует доведения до подтверждённых возможностей checkpoint.
3. Использовать существующий upstream window planner. Не переносить research environment flags и GPU-head эксперимент в поддерживаемый путь автоматически. Они сохранены для воспроизводимости и диагностики, а не как готовый публичный API.
4. Добавить matched-window MLX oracle: тот же frontend, границы/контекст, отбрасывание контекстных encoder frames, stitching и один CTC collapse. Проверить границы, реальные повторы и весь корпус против исходного `f16-stock25` результата.
5. Выполнить оставшиеся задачи change: native fixtures, error/cancellation/capabilities, regression suite и пакет C/Swift. Не переписывать уже работающую конвертацию и вычисления без выявленного расхождения.

## Ограничения запуска сохранённых скриптов

Это снимки исходного исследования, не автономный установленный инструмент. Их `ROOT` определяется расположением файла; они ожидают рабочий каталог `.local/asr-quality/evaluations/gigaam600m-transcribe-metal-20261019/`, соседние прежние исследования, приватный корпус и локальные веса. Не запускать их из `research/scripts/`: сначала восстановить ожидаемую структуру по путям `manifest.json` либо адаптировать пути при apply. Существующие `runs.jsonl` нужно сохранить перед повторным прогоном; inference-скрипты отказываются их перезаписывать.

Python запускать через `uv --native-tls run --no-project --python 3.13`. Метаданные/веса Hugging Face на этом Mac получать через настроенный HTTP proxy. Конвертация, моделирование и выпуск новых артефактов при сохранении этого handoff не запускались.

Патч содержит производные части MIT-кода transcribe.cpp; его copyright и условия сохранены в `LICENSE.transcribe.cpp`. Условия распространения весов и других зависимостей проверяются отдельно перед принятием пакета.
